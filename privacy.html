Privacy policy and terms

Last updated: November 25, 2026

Who uses this app

Granite Local is a personal app with one user: its owner. It is not available to anyone else.

What data it accesses

With the owner's consent, through Google OAuth, the app reads the owner's Google Calendar events and Gmail messages, creates calendar events, and creates Gmail drafts. It does not send email.

How the data is used

Data is processed only on the owner's own computer by a locally run AI model so it can answer the owner's questions. It is not sold, shared, or sent to third parties, and it is not used to train AI models.

Storage

The app keeps only its OAuth token, on the owner's computer. Google data is fetched when needed and is not kept long term.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Granite Local's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Terms

This is a personal tool provided as is, with no warranty, for its owner's private use only.
